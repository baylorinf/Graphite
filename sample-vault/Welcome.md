# Welcome to Graphite 👋

This is your **vault**: a plain folder of Markdown files on your computer. Every note is a `.md` file, so you can open them in any editor or point the app at an existing Obsidian vault.

## Get started
- Link notes with double brackets: [[Markdown Cheatsheet]] or [[Ideas/Project Alpha|an aliased link]]
- Links to notes that don't exist yet look faded: [[A note I haven't written]]. Click to create it.
- Type `[[` in the editor to autocomplete note names
- Tag things with #start-here or #ideas, then click a tag to search it
- Embed another note with `![[Note]]`:

![[Markdown Cheatsheet#Callouts]]

## Keyboard shortcuts
| Action | Shortcut |
| --- | --- |
| Quick switcher (open/create note) | `Ctrl+O` |
| Command palette | `Ctrl+P` |
| New note | `Alt+N` |
| Toggle edit / reading view | `Ctrl+E` |
| Graph view | `Ctrl+G` |
| Search all notes | `Ctrl+Shift+F` |
| Today's daily note | `Alt+D` |
| Rename note | `F2` |
| Back / forward | `Alt+←` / `Alt+→` |
| Bold / italic / link | `Ctrl+B` / `Ctrl+I` / `Ctrl+K` |
