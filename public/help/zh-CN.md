# Graphite 使用指南

Graphite 是一款把笔记相互链接起来的笔记应用。每篇笔记都是电脑上普通的 Markdown（`.md`）文件，所以你的笔记永远不会被锁在某个软件里。

> [!tip] 随时按 **F1**、点击左侧边栏的 **?** 按钮，或打开命令面板（按 `Ctrl+P` 后输入“帮助”）即可打开本指南。

## 交大 Canvas：课件和截止时间

在新标签页或 **设置 → 通用** 打开 **交大 Canvas**，选择 **使用 jAccount 登录**。点 **一键拉取所有课程资料**，将课件、作业说明和可下载的附件保存到笔记库。点进课程可读 **课程大纲与要求**，也可查每份作业的说明和截止时间。

在课程的 **作业** 里选中对应作业，点 **从笔记库选择** 或从电脑添加文件。可勾选多份，核对课程、作业名和文件后再确认。支持的文件上传作业可在 Graphite 查看校方回执。使用外部工具或需要额外步骤时，可打开对应的学校页面。个人日历订阅链接可在 **日历订阅** 中添加。

## 你的仓库
- **仓库**是存放笔记的文件夹，位置可在 **设置 → 通用** 中查看。
- 想使用其他文件夹（例如已有的 Obsidian 仓库），用 `node server.js "D:\仓库\路径"` 启动即可。
- 删除的笔记会被移到仓库的 `.trash` 文件夹，可以随时找回。
- 在其他程序里修改的文件会立即显示在应用中。
- 笔记标题可以包含任何字符。Windows 文件名不允许的字符（如 `: ? / " < > * | \ # ^ [ ]`）会被替换成外观相似的字符保存（例如 `:` 变为 `꞉`）。用普通字符书写的链接仍然能找到这篇笔记。
- 在桌面版中，有新版本时左侧边栏和状态栏会出现 **更新** 按钮。点击即可安装，会先保存你的笔记，然后应用自动重新打开。

## 写作
- 用右上角的按钮或 `Ctrl+E` 在 **编辑**、**分栏**（编辑器与预览左右并排）和 **阅读** 之间切换。
- 笔记会自动保存，按 `Ctrl+S` 可立即保存。
- 修改标题即可重命名笔记，所有指向它的链接都会自动更新。
- 把图片粘贴或拖入编辑器，会保存到 `attachments/` 并插入笔记。

| 格式 | 输入 |
| --- | --- |
| 粗体 / 斜体 | `**粗体**` / `*斜体*`（或 `Ctrl+B` / `Ctrl+I`） |
| 高亮 | `==高亮==` |
| 删除线 | `~~文字~~` |
| 标题 | `# 标题`、`## 小标题` |
| 任务 | `- [ ] 待办`、`- [x] 已完成` |
| 代码 | `` `行内代码` `` 或用 ```` ``` ```` 包围的代码块 |
| 隐藏注释 | `%%只在编辑时可见%%` |

全部语法和可复制的示例都在 <a href="#" data-help-page="markdown">Markdown 速查表</a> 中。

## 链接笔记
- `[[笔记名]]` 链接到一篇笔记，输入 `[[` 会出现候选列表。
- `[[笔记名|显示文字]]` 可修改链接文字，`[[笔记名#标题]]` 可跳到指定标题。
- `![[笔记名]]` 嵌入整篇笔记；`![[图片.png]]` 显示图片，`![[图片.png|300]]` 设置宽度。
- 指向尚不存在的笔记的链接会显示为淡色，点击即可创建该笔记。
- 右侧边栏显示 **反向链接**（链接到本笔记的笔记）、**未链接的提及**、**出链**、**标签** 和 **大纲**。

## 整理
- **文件夹：** 拖动笔记和文件夹即可移动，右键可进行更多操作。
- **标签：** 在正文任意位置写 `#标签`，或在笔记开头的属性里写 `tags: [a, b]`。
- **属性：** 在笔记开头写一段用 `---` 包围的 `键: 值` 行。
- **日记：** 按 `Alt+D` 在 `Daily Notes/` 中打开今天的日记。

> [!example] 属性示例
> ```
> ---
> tags: [项目, 想法]
> status: 进行中
> ---
> ```

## 查找
- **快速切换**（`Ctrl+O`）：输入名称的一部分来打开笔记；若没有匹配，按 `Shift+Enter` 新建。
- **搜索**（`Ctrl+Shift+F`）：搜索所有笔记，条件可以组合使用：

| 搜索内容 | 找到 |
| --- | --- |
| `会议 记录` | 同时包含两个词的笔记 |
| `"完整短语"` | 完全一致的短语 |
| `#项目` | 带有该标签的笔记（包括 `#项目/子标签`） |
| `path:想法` | 某个文件夹中的笔记 |
| `file:草稿` | 名称包含“草稿”的笔记 |

- **关系图谱**（`Ctrl+G`）：一张有点像大脑记忆的笔记地图。拖动可移动，滚轮可缩放。**局部图谱** 只显示当前笔记及与之相连的笔记。
  - **脑区：** 联系紧密的笔记会聚成彩色区域，以它们共同的标签或联系最多的笔记命名。
  - **联想：** 用虚线连接内容相似、但你还没有链接的笔记。它们是通过比较笔记中的词语找到的。
  - **记忆：** 记得牢的笔记（根据测验结果）会发亮，正在遗忘的会变暗，该复习的笔记外面有一圈闪动的橙色圆环。
  - **单击笔记** 就是“想起它”：一道脉冲沿着它的联系扩散开来，卡片按强弱列出它 **让你想到** 的笔记，并显示记忆状态以及 **打开**、**测验一下**、**从这里漫游** 按钮。**双击** 打开笔记。
  - **让思绪漫游** 会沿着最强的联系从一个想法走到下一个，偶尔跳到不相关的想法（⤳），并在底部留下可点击的 **思路**。

## 标注框
在引用开头写 `[!类型]` 即可生成彩色标注框。类型包括 `note`、`tip`、`warning`、`danger`、`success`、`question`、`example`、`quote` 等。在类型后加 `-` 表示默认折叠，加 `+` 表示可折叠但默认展开。

```
> [!warning]- 点击展开
> 展开前一直隐藏。
```

## 数学公式（LaTeX）
和 Obsidian 一样，可以用 LaTeX 书写公式：
- **行内公式：** 写 `$E = mc^2$`，会在句子中显示为 $E = mc^2$。
- **独立公式：** 在公式前后各放一行 `$$`，公式会单独居中显示：

```
$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
```

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

- **化学式：** 写 `$\ce{2H2 + O2 -> 2H2O}$`，会显示为 $\ce{2H2 + O2 -> 2H2O}$。
- **金额不受影响：** `$` 后面紧跟空格或数字时不会被当作公式。想在任何地方显示美元符号，请输入 `\$`。
- **命令：** 命令面板中的 **插入公式块** 会添加一个空的 `$$` 块。
- **错误：** 有错误的公式会以红色显示，方便你看出哪里需要修改。
- **完整列表：** <a href="#" data-help-page="latex">LaTeX 速查表</a>列出了约 160 个命令及其效果。也可以在命令面板中选择 **打开 LaTeX 速查表**。

## 复习与记忆
Graphite 帮你记住你写下的内容。笔记会自动变成题目：

- 句子中 `==高亮==` 或 **加粗** 的词会变成填空题，`- **术语**：解释` 会变成“什么是术语？”。
- 一行写 `问题 :: 答案`（或按问题、只有 `?` 的一行、答案的顺序书写）会变成抽认卡。
- 每个带标题的章节会变成“关于……你还记得什么？”。

**检查错误：** 顶部的放大镜按钮（`Ctrl+Shift+E`）会检查当前打开的笔记。每个问题都显示为“原文 → 修改后的文字”，并附简短说明。点击 **应用** 即可修正（`Ctrl+Z` 可撤销），点击 **在笔记中显示** 跳到该处，或点击 **忽略**。不开 AI 时，基础检查会找出重复的词、缺少的空格、失效的 `[[链接]]`（并推荐最接近的笔记）、未闭合的 `**`/`==` 以及跳级的标题。开启 AI 后，AI 还会检查事实、拼写、语法和表达不清的句子。

**测验：** 顶部的学士帽按钮（`Ctrl+Shift+K`）用当前笔记出题测验你。开启 AI 后，AI 会为这篇笔记额外出题（笔记内容每变一次只出一次）。离开刚写过的笔记时，会弹出小卡片提议 **检查** 或 **测验一下**。两者也都在右键菜单中。

**复习计划：** 在复习页面（或命令面板）点 **生成复习计划**。填写考试、日期、考试范围，勾选范围内的文件夹，设定每天的时间。AI 会排好到考试前每一天的计划，先复习薄弱和到期的内容，并带复选框保存到 `<课程>/复习计划 Review Plans`。

**试卷分析：** 在复习页面点 **分析试卷**，或在文件列表里右键一个 PDF 或笔记。AI 会列出每道题的知识点和对应的笔记；如果试卷上有你的答案或分数，还会说明错在哪里、为什么错，最后给出建议和计划，保存到 `<课程>/考试分析 Exam Analysis`。扫描版 PDF 请选 Claude Code。

**整理格式：** 顶部的 🪄 按钮（`Ctrl+Shift+Y`）会让当前笔记的格式和同一文件夹里的其他笔记一致：frontmatter、标题、编号、来源行和 Related 行。内容不变；会先显示前后对比预览，应用后可以按 `Ctrl+Z` 撤销。

**学习页面：** 交互式复习页面在每门课的学习资料文件夹（默认 `学习页面 Study Pages`）里。在文件列表中点开（或点它的链接）就会在 🎓 标签页中打开。

**错题本与 PDF 卡片：** 复习页的错题本和 PDF 卡片支持按题干或来源搜索。重做错题时可以打开原卷，点 **返回作答** 接着写。关闭软件后，也可以继续尚未提交的草稿。

**Word 和 PowerPoint：** `.docx` 会以易读的页面打开（点 **精确版式** 可看到和 Word 打印完全一样的效果）。`.doc`、`.ppt` 和 `.pptx` 会以你电脑上的 Word 或 PowerPoint 生成的 PDF 打开，可以用页码、缩放、搜索和“链接到某一页…”；第一次打开要几秒，之后会立刻打开。**保存 PDF 副本** 会在原文件旁边保存一个 PDF。

**每日复习：** 左侧边栏的大脑按钮（`Alt+R`）会显示今天待复习的题数。每答一题就选 **重来**、**困难**、**良好** 或 **简单**，应用会在你快要忘记时安排下一次复习（间隔重复）。

**相关笔记：** 右侧边栏会推荐主题相近、但还没有链接的笔记。点击 **链接** 即可把它们连起来。

## 用 AI 学习：执行者与学习设置
Graphite 的学习功能都叫 Graphite 自己的名字：**Graphite 学习助手**（右侧聊天）、**Graphite 摘录**（✦ 标记不熟悉/有趣的内容并整理进笔记）、**Graphite 练习与测验**，以及检查、复习计划、试卷分析、模拟卷、整理格式、**总结 PDF** 和查找新课程文件。真正干活的 AI 叫 **执行者**，在 **设置 → AI** 中为每项任务分别选择：

- **Claude Code**：使用本机的 Claude Code 窗口，不需要密钥，窗口连接时可用（在窗口里说“connect to Graphite”）。安装技能和钩子在 **设置 → Claude Code**。
- **本地框架**：**DeepSeek Harness**、**Codex CLI** 等，由 Graphite 在本机启动，自己读取文件（只读）。是否已安装、版本和自定义路径都显示在 **设置 → AI → 本地框架**。DeepSeek Harness 使用 DeepSeek 的密钥。
- **API 模型**：Anthropic（Claude）、OpenAI、Google Gemini、DeepSeek、通义千问、Kimi、智谱 GLM，或任何兼容 OpenAI 的服务。在 **API 密钥** 里粘贴密钥并点 **测试密钥**。只有对应的笔记或 PDF 文字会发给你选的服务商。每项工作还有 **此任务的模型**：保持 **默认**（密钥框里的模型），或选同一服务商的其他模型，例如测验用 Haiku、试卷分析用 Opus。

学习助手顶部显示“执行者：…”，每条回答下也标出是谁回答的；切换执行者后功能名称不变。

**学习设置：** **设置 → 学习设置** 统一保存课程目录、课程名称映射（如 `LA = Linear Algebra`）、跳过的目录、另外查找（最近的下载/桌面/文档）、只读目录、学习档案位置、学习资料位置、个人简介，以及聊天、阅读和笔记语言。保存一次，所有执行者都使用同一份设置（保存在本机 `~/.graphite/study.json`，以后接入的本地 Agent 也能读取），每项任务只取它需要的部分：导入用课程目录和跳过项，摘录整理用只读目录和学习档案位置，AI 写的笔记用笔记语言。设置不会扩大任何 AI 的读写权限。从旧版升级时，原「设置 → AI」与「设置 → Claude Code」中的值会自动合并；两边不一致时都会保留，并在学习设置顶部列出供你核对。

## 总结 PDF
在 PDF 工具栏点 **总结**，或在文件树中右键 PDF 选 **总结这份 PDF**（命令面板中也有）。可以只总结部分页码：留空表示全部；`0`、超出总页数或越界的范围会被直接拒绝，不会发送任何内容。默认保存在 PDF 所在的文件夹；如果这份 PDF 是从库外的课程目录导入的，或放在以课程代号命名的文件夹里，还会列出映射到的课程目录供你选择。只读目录不能选。

生成的是可编辑的 Markdown 笔记：概述、按章节的要点、关键概念、公式，每条后面都有 `p. N` 链接，点击即打开原 PDF 的那一页。预览中会显示保存路径，点 **保存** 才会写入。如果同名总结已存在，可以 **另存为新笔记**，或明确选择 **更新原笔记**（如果你手动改过，会再提醒一次）。扫描页没有文字时，API 模型无法读取，请选 Claude Code 或本地框架；中途点 **停止** 或保存失败都不会改动已有笔记。

## 讲义对照与代码编辑
**对照笔记：** 打开讲义或笔记，点击顶部的 **对照笔记**，再选择要一起看的文件。写题解时，点击 **引用当前页** 即可把讲义的页码链接插入光标处。Graphite 会为这个笔记库记住讲义和页码。

**代码编辑器：** 在文件树中打开 `.cpp`、`.h`、`.py` 等源文件，或选择 **新建代码文件** 开始一道练习。可以直接编辑、`Ctrl+F` 查找、用 `Tab` 和 `Shift+Tab` 调整缩进，按 `Ctrl+S` 保存（原有编码和换行符保持不变）。**复制当前行链接** 得到的 `[[main.cpp#L42]]` 粘到题解里，以后点它就跳回这一行。遇到其他程序同时修改文件，可用 **另存副本** 保留自己的版本。编译和运行仍在你常用的开发环境里完成。

## 代码模式（学习 / 代码）
左侧栏顶部的 **学习** 和 **代码** 按钮在笔记和编程之间切换。随时都能切换，程序运行中、编程助手回答中、笔记或代码还没保存时也可以：不会中断，也不会丢内容，两边都保持离开时的样子。关闭 Graphite 后，它也会记住上次的模式和项目。

- **项目：** 用 **打开文件夹…** 选择电脑上的任意文件夹（或 **改用本仓库**）。左侧是真实的文件夹树，可以用标签页同时打开多个文件。未保存的改动在关闭 Graphite 后也会保留。
- **运行：** **▶ 运行当前文件** 只编译运行打开的这个文件（同一文件夹里各有 `main()` 的几道练习互不干扰）。**运行项目…** 可以勾选组成一个程序的多个源文件。程序需要的输入写在 **输入** 里；输出、问题和调试（断点、单步、变量）都在下方面板。
- **编程助手**（右侧）：用 **设置 → AI** 中为“编程助手”选择的 AI，解释选中的代码、说明编译错误或提出修改建议。发送前选择附带的内容：**当前选区**、**附上当前文件**（编辑器里的当前内容，含未保存的改动）或 **仅提问**；输入框上方会写明这次具体发送什么。回复只供阅读，不会执行命令或改动文件。每个项目有自己的对话。
- **代码模式的快捷键：** `Ctrl+P` 在项目中查找文件，`Ctrl+G` 跳到行，`F5` 调试，`Ctrl+F5` 运行，`F9` 断点，`F10`/`F11` 单步。在学习模式中，这些按键保持原来的作用。
- **代码字体：** **设置 → 外观 → 代码字体** 和 **代码字号** 会改变项目编辑器和从笔记打开的源码文件，不影响笔记正文。

## 多设备同步
Graphite 通过云盘文件夹同步。把仓库放在 OneDrive（Windows 自带）、Dropbox、Google Drive 或 iCloud 云盘中，然后在每台电脑上打开同一个文件夹。**设置 → 同步** 会显示仓库是否已同步，以及云盘文件夹的位置。

- **在两台设备上同时编辑：** 如果修改的是笔记的不同部分，会自动合并。如果改的是同一行，你的版本保留在笔记中，另一个版本会以“(conflict …)”副本保存在旁边，不会丢失任何内容。
- **冲突副本**（无论来自 Graphite 还是云盘应用）都会列在 **设置 → 同步** 中。有冲突副本时，状态栏会显示 ⚠ 提示。
- **在手机上：** 用免费的官方 Obsidian 应用打开同一个文件夹。iPhone 和 iPad 上，把仓库放在 iCloud 云盘中。Android 上，用 FolderSync 或 Syncthing 等应用把文件夹复制到手机。

## 插件
Graphite 可以运行许多 **Obsidian 社区插件**。

1. 打开 **设置**（齿轮图标或 `Ctrl+,`），进入 **第三方插件**。
2. 点击 **开启第三方插件**。插件是他人编写的代码，可以修改你的笔记，请只使用你信任的插件。
3. 点击 **浏览**，搜索后点击 **安装**。也可以把插件文件夹复制到仓库内的 `.obsidian/plugins/` 中。
4. 用开关启用插件。如果插件有选项，旁边会出现齿轮图标。

> [!info] 支持哪些功能
> 插件的命令、侧边栏图标、状态栏、设置页面、Markdown 与代码块渲染、编辑器输入建议、文件菜单、弹出窗口和通知都可以正常使用。会打开独立侧边面板或修改编辑器本身（CodeMirror 扩展）的插件无法完全运行。插件加载失败时，原因会显示在插件名称下方。

插件的文件夹结构与 Obsidian 相同。用 Graphite 打开 Obsidian 仓库时，已安装的插件会自动出现。

### 管理插件
- **卸载：** 点击插件旁的垃圾桶图标即可删除。它的文件夹会被移到仓库的 `.trash`，可以随时恢复。
- **重新加载插件**（“已安装插件”旁的环形箭头）会重新加载所有插件，适合在复制或修改插件文件夹之后使用。命令面板中也有这个命令。
- **打开插件文件夹**（文件夹图标）会在文件资源管理器中打开 `.obsidian/plugins/`。

### 示例插件：Note Stats
Graphite 自带一个小型示例插件 **Note Stats**。开启后可以使用：
- 状态栏中的阅读时间
- 统计窗口（侧边栏的图表图标，或命令“Note Stats: Show statistics for this note”）
- 显示仓库中笔记、链接和标签数量的 ```` ```stats ```` 代码块
- 输入 `@today`、`@tomorrow` 或 `@yesterday` 时的日期建议
- 右键点击文件时的 **Copy wikilink**

它的代码位于 `.obsidian/plugins/note-stats/main.js`，是编写自己插件的简短示例。

### Dataview
Dataview 查询（```` ```dataview ```` 代码块）的结果会显示在 **阅读** 和 **分栏** 视图中。Dataview 在编辑器内的实时预览无法使用，因为它需要 Graphite 没有的编辑器功能。

## 语言与外观
- 用 🌐 按钮或在 **设置 → 通用** 中切换语言。应用默认使用系统语言。
- 用月亮按钮切换浅色和深色主题。
- 在 **设置 → 外观** 中可以更改正文字体、代码字体和字号，也可以在编辑时使用等宽字体。
- 拖动侧边栏边缘可调整宽度，用顶部的按钮可隐藏或显示侧边栏。
