# Graphite ガイド

Graphite は、ノート同士をつなげて考えるためのノートアプリです。すべてのノートはパソコン上のふつうの Markdown（`.md`）ファイルなので、データが特定のアプリに閉じ込められることはありません。

> [!tip] このガイドは **F1**、左のリボンの **?** ボタン、またはコマンドパレット（`Ctrl+P` を押して「ヘルプ」と入力）でいつでも開けます。

## 上海交通大学 Canvas の授業資料と締切

Graphite はあなた自身の jAccount で上海交通大学 Canvas にログインし、見られるコースを読み込み、授業資料を保管庫に整理し、締切の表示や課題の提出をアプリ内で行います。API キーは不要で、大学のパスワードは大学のログインページでしか入力しません。

**1. ログイン。**左下のリボンの **Canvas ボタン**（建物のアイコン）をクリックするか、新しいタブで上海交通大学 Canvas を選び、**jAccount でログイン**をクリックします。開いた大学のページでログイン（パスワードまたは QR コード）を済ませると、ウィンドウは自動で閉じます。待機中と表示されている間は、ほかに押すものはありません。

**2. コースの読み込み。**その後 Graphite はバックグラウンドでコースを 1 つずつ読み込み、同期バーに進捗（例「3/6」）を表示します。その間も普通に作業でき、読み込んだコースから順に表示されます。アプリを開いている間はコース一覧が 15 分ごとに更新されます。すぐ更新するには**今すぐ同期**をクリックします。

**3. ファイルは自動で整理。**各コースの**コースフォルダー**で保管庫のフォルダーを選びます（Graphite がコース名から候補を出します。例：线性代数 → *Linear Algebra*。新しく作ることもできます）。**新しいスライドを自動同期**をオンにすると、起動時とその後 3 時間ごとに新しいファイルをダウンロードして整理します：スライドは `<コース>/课件 Slides/`、宿題は `作业 Homework/`、試験と解答は `复习资料/`、履修要件はコースフォルダーへ。PowerPoint と Word には PDF のコピーも作られます。今すぐ行うには**全授業の資料を保存**、1 コースだけなら**授業ファイルをまとめて保存**をクリックします。
- すでにあるファイルはスキップし、上書きは一切しません。同じ名前で中身が違うファイルは「名前 (2)」として保存します。
- 削除したファイルは再ダウンロードされません。
- 新しいファイルは Canvas ボタンのバッジと**コースフォルダーに追加**カードで知らせ、コースの目次ノートにリンクが 1 行加わります。
- Canvas ウィンドウで手動ダウンロードしたファイルは保管庫直下の `Downloads/` に入ります。
- 旧版の `Canvas/` フォルダーは初回起動時に一度だけ各コースフォルダーへ振り分けられます。

**4. 要件・締切・提出。**課題、お知らせ、ページ、ディスカッションは Graphite のリーダーで開きます。表示できないもの（小テストの受験、ディスカッションへの返信）は **Graphite の Canvas ウィンドウで開く**を使います。**シラバス・履修要件**には教員が公開した説明が表示されます。**今後30日間**には締切と残り日数が並びます。締切の横の**課題を提出**をクリックすると、そのコースの宿題フォルダーから最も可能性の高いファイル（課題番号、タイトル、新しさの順）を選んでプレビューします。コース・課題・ファイルを確認し、**確認して提出**をクリックしてください。確認前には何も送信されません。コースの**課題**で**保管庫から選択**や**パソコンから選択**を使って自分で選ぶこともできます。結果がはっきりしないときは、再提出の前に**提出状況を確認**をクリックします。

**5. カレンダーとログアウト。**Canvas のカレンダーフィードのリンクを**カレンダーの購読**に貼ると、すべての予定が表示されます。**大学のポータルからログアウト**は大学サイトのログインを終えるだけで、**アカウントの連携を解除**はこのパソコンに保存したアカウント、購読、コースのキャッシュも消去します。保管庫に保存済みのファイルは残ります。

**所要時間の目安。**
- jAccount ログイン：約 1 分（入力やスキャンの速さによります）。
- 初回のコース読み込み：1 コースあたり 30 秒〜1 分、6 コースで 3〜5 分。
- 2 回目以降：保存済みのコースがすぐ表示され、更新は通常 1〜3 分。
- 全授業の資料を保存：1 ファイルあたり 1〜3 秒、数十ファイルで 1〜2 分。PDF のコピーは 1 件につき数秒追加。
- 提出：確認後、通常 10〜30 秒で受領が表示されます。

## 切り取り、整理、復習

PDF や学習ページからテキストをコピーすると、数式や書式が崩れます。代わりに**切り取り**（`Alt+S`、PDF ツールバーのはさみ、選択バーの**切り取り**）で、数式・図・表を枠で囲みます。キャプチャーパネルでは：

- **Graphie に質問**：スクリーンショット付きでチャットを開きます。
- **Markdown に**：**設定 → AI** の「スクリーンショット → Markdown」の AI が `$…$` 数式付き Markdown に書き起こします。使う前に編集できます。
- **ノートに追加**：ノートと**見出し**を選んで追加し、ページへのリンクを付けます。Markdown がなければ画像を埋め込みます（`attachments/` に保存）。
- **よく知らない**：Graphie がすぐチャットで説明し、Claude Inbox にも保存、明日の復習にカードが出ます。
- **面白い**：選んだ見出しの下に `[!tip]` として整理（または Graphie に任せる）。
- **カード** / **間違いノート**：コースの**デッキ**に入るカード（間隔反復）か、解き直す問題。

テキストを選択したときの選択バーにも同じ操作があります。**復習**ページでは、デッキごとにそのコースだけを復習するボタンがあります。

## 保管庫
- **保管庫**はノートを保存するフォルダです。場所は **設定 → 一般** で確認できます。
- 既存の Obsidian 保管庫など別のフォルダを使うには、`node server.js "D:\保管庫のパス"` で起動します。
- 削除したノートは保管庫の `.trash` フォルダに移動されるので、あとから元に戻せます。
- 他のアプリでファイルを変更すると、すぐにこのアプリにも反映されます。
- ノートのタイトルにはどんな文字でも使えます。`: ? / " < > * | \ # ^ [ ]` のように Windows のファイル名に使えない文字は、よく似た文字に置き換えて保存されます（例：`:` は `꞉` になります）。ふつうの文字で書いたリンクでも、そのノートが見つかります。
- デスクトップアプリでは、新しいバージョンがあると左のリボンとステータスバーに **アップデート** ボタンが表示されます。クリックするとインストールされます。ノートは先に保存され、アプリは自動的に再び開きます。

## 書く
- 右上のボタンか `Ctrl+E` で **編集**、**分割**（エディタとプレビューを左右に表示）、**閲覧** を切り替えます。
- ノートは自動で保存されます。`Ctrl+S` ですぐに保存することもできます。
- タイトルを書き換えるとノート名が変わり、そのノートへのリンクもすべて自動で更新されます。
- 画像をエディタに貼り付けるかドロップすると、`attachments/` に保存されて埋め込まれます。

| 書式 | 入力 |
| --- | --- |
| 太字 / 斜体 | `**太字**` / `*斜体*`（または `Ctrl+B` / `Ctrl+I`） |
| ハイライト | `==ハイライト==` |
| 取り消し線 | `~~テキスト~~` |
| 見出し | `# 見出し`、`## 小見出し` |
| タスク | `- [ ] 未完了`、`- [x] 完了` |
| コード | `` `インライン` `` または ```` ``` ```` で囲んだブロック |
| 非表示コメント | `%%編集中だけ表示%%` |

すべての書き方とコピーできる例は <a href="#" data-help-page="markdown">Markdown チートシート</a> にあります。

## ノートをリンクする
- `[[ノート名]]` でノートにリンクします。`[[` と入力すると候補が表示されます。
- `[[ノート名|表示する文字]]` でリンクの文字を変更でき、`[[ノート名#見出し]]` で見出しに移動できます。
- `![[ノート名]]` でノート全体を埋め込みます。`![[画像.png]]` で画像を表示し、`![[画像.png|300]]` で幅を指定します。
- まだ存在しないノートへのリンクは薄く表示されます。クリックするとそのノートが作成されます。
- 右サイドバーには **バックリンク**（このノートへのリンク）、**リンクされていない言及**、**発リンク**、**タグ**、**アウトライン** が表示されます。

## 整理する
- **フォルダ：** ノートやフォルダをドラッグして移動します。右クリックでその他の操作ができます。
- **タグ：** 本文のどこにでも `#タグ` と書くか、ノート先頭のプロパティに `tags: [a, b]` と書きます。
- **プロパティ：** ノートの先頭に `---` で囲んだ `キー: 値` の行を書きます。
- **デイリーノート：** `Alt+D` で今日のノートを `Daily Notes/` に開きます。

> [!example] プロパティの例
> ```
> ---
> tags: [プロジェクト, アイデア]
> status: 進行中
> ---
> ```

## 探す
- **クイックスイッチャー**（`Ctrl+O`）：名前の一部を入力してノートを開きます。該当がなければ `Shift+Enter` で新規作成します。
- **検索**（`Ctrl+Shift+F`）：すべてのノートを検索します。条件は組み合わせられます。

| 検索語 | 見つかるもの |
| --- | --- |
| `会議 メモ` | 両方の語を含むノート |
| `"完全一致の文"` | その文と完全に一致する箇所 |
| `#プロジェクト` | そのタグを持つノート（`#プロジェクト/子` も含む） |
| `path:アイデア` | フォルダ内のノート |
| `file:下書き` | 名前に「下書き」を含むノート |

- **グラフビュー**（`Ctrl+G`）：脳の記憶のように働くノートの地図です。ドラッグで移動、ホイールで拡大縮小。**ローカルグラフ** は現在のノートとつながるノートだけを表示します。
  - **領域：** 強くつながったノートが色付きのまとまりになり、共通のタグか最もつながりの多いノートの名前が付きます。
  - **連想：** まだリンクしていない、似た考えのノート同士を点線で結びます。ノートの単語を比べて見つけます。
  - **記憶：** よく覚えているノート（クイズの結果から）は明るく光り、忘れかけのノートは薄くなり、復習の時期のノートにはオレンジの輪が脈打ちます。
  - **ノートをクリック** すると「そのことを考え」ます。つながりに沿って信号が広がり、カードに **思い浮かぶもの** が強い順に表示されます。記憶の状態と **開く**・**クイズに挑戦**・**ここからさまよう** ボタンもあります。**ダブルクリック** でノートを開きます。
  - **思考をさまよわせる** と、最も強いつながりをたどって考えから考えへ移り、ときどき関係のない考えへ飛びます（⤳）。下にクリックできる **思考の流れ** が残ります。

## コールアウト
引用の先頭に `[!種類]` と書くと色付きの囲みになります。種類は `note`、`tip`、`warning`、`danger`、`success`、`question`、`example`、`quote` などです。種類のあとに `-` を付けると最初から折りたたまれ、`+` を付けると開いた状態で折りたためるようになります。

```
> [!warning]- クリックで展開
> 開くまで隠れています。
```

## 数式（LaTeX）
Obsidian と同じように、LaTeX で数式を書けます。
- **インライン：** `$E = mc^2$` と書くと、文中に $E = mc^2$ と表示されます。
- **ブロック：** 数式の前後の行に `$$` を置くと、独立した行に中央揃えで表示されます。

```
$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
```

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

- **化学式：** `$\ce{2H2 + O2 -> 2H2O}$` と書くと $\ce{2H2 + O2 -> 2H2O}$ と表示されます。
- **金額の表記はそのまま：** `$` の後にスペースや数字が続く場合は数式として扱われません。ドル記号を表示したいときは `\$` と入力します。
- **コマンド：** コマンドパレットの **数式ブロックを挿入** で空の `$$` ブロックを追加できます。
- **誤り：** 誤りのある数式は赤で表示されるので、どこを直せばよいかわかります。
- **一覧：** <a href="#" data-help-page="latex">LaTeX チートシート</a>に約160個のコマンドと表示例があります。コマンドパレットの **LaTeX チートシートを開く** からも開けます。

## 復習と記憶
Graphite は書いた内容を覚えるのを手伝います。ノートは自動的に問題になります。

- 文中の `==ハイライト==` や **太字** の語は穴埋め問題に、`- **用語**: 説明` は「用語とは？」になります。
- 1行の `質問 :: 答え`（または質問・`?` だけの行・答え）はフラッシュカードになります。
- 見出しのある各セクションは「…について覚えていることは？」になります。

**誤りのチェック：** 上部の虫めがねボタン（`Ctrl+Shift+E`）で開いているノートをチェックします。問題ごとに「元の文 → 修正後の文」と短い理由が表示されます。**適用** で修正（`Ctrl+Z` で元に戻せます）、**ノートで表示** でその箇所へ移動、または **無視**。AI なしでも、基本チェックで同じ単語の重複、スペースの抜け、壊れた `[[リンク]]`（近いノート名を提案）、閉じていない `**`/`==`、見出しレベルの飛びを見つけます。AI をオンにすると、AI が事実・綴り・文法・分かりにくい文もチェックします。

**クイズ：** 上部の角帽ボタン（`Ctrl+Shift+K`）で開いているノートのクイズをします。AI をオンにすると、AI がそのノートについて独自の問題を追加します（ノートの内容が変わるたびに一度だけ作成）。書き込んだノートを離れると、小さなカードで **チェック** か **クイズに挑戦** を提案します。どちらも右クリックメニューにあります。

**AI の選び方：** **設定 → AI** では、作業ごと（チェック、クイズの問題、チャット、復習計画、試験分析、書式を整える）に AI を選べます。**Claude Code** はこのパソコンの Claude ウィンドウを使い、キーは不要ですが、接続中のときだけ動きます（ウィンドウで「connect to Graphite」と言います）。**API モデル**はご自身のキーでいつでも使えます：Anthropic（Claude）、OpenAI、Google Gemini、DeepSeek、Qwen、Kimi、GLM、または OpenAI 互換のサービス。**API キー** の欄にキーを貼り付けて **キーをテスト** を押すと、そのプロバイダーの最新モデル一覧も読み込まれます。キーはこのパソコンにのみ保存され、送られるのはその作業のノートや試験問題だけで、そのプロバイダーにだけ送られます。各作業には **この作業のモデル** もあり、**既定**（キー欄のモデル）のままにするか、同じプロバイダーの別のモデルを選べます。チェックとチャットでは、その場でも AI を切り替えられます。

**復習計画：** 復習ページ（またはコマンドパレット）で **復習計画を作る**。試験、日付、範囲を入力し、範囲のフォルダにチェックを入れ、1 日の時間を決めます。AI が試験日までの毎日の計画を苦手・復習時期の項目から順に作り、チェックボックス付きで `<科目>/复习计划 Review Plans` に保存します。

**試験問題の分析：** 復習ページの **試験問題を分析**、またはファイル一覧で PDF かノートを右クリック。AI が全問題をテーマと対応するノート付きで整理し、答案や点数があれば間違いの原因を説明し、アドバイスと計画を加えて `<科目>/考试分析 Exam Analysis` に保存します。スキャンした PDF には Claude Code を選んでください。

**書式を整える：** 上部の 🪄 ボタン（`Ctrl+Shift+Y`）で、開いているノートの書式を同じフォルダの他のノートに合わせます：frontmatter、見出し、番号付け、出典と Related の行。内容は変わりません。先に変更前後のプレビューが出て、`Ctrl+Z` で元に戻せます。

**学習ページ：** インタラクティブな復習ページは、各科目の `学习页面 Study Pages` フォルダにあります。ファイル一覧でクリック（またはリンクをクリック）すると 🎓 タブで開きます。

**Word と PowerPoint：** `.docx` は読みやすいページとして開きます（**正確なレイアウト** で Word の印刷どおりに表示）。`.doc`・`.ppt`・`.pptx` は、インストール済みの Word や PowerPoint が作った PDF として開き、ページ番号・拡大縮小・検索・「ページへのリンク…」が使えます。初回は数秒かかり、2 回目からはすぐ開きます。**PDF のコピーを保存** で元のファイルの隣に PDF を保存します。

**毎日の復習：** 左のリボンの脳のボタン（`Alt+R`）に今日の問題数が表示されます。答えごとに **もう一度**・**難しい**・**普通**・**簡単** を選ぶと、忘れる直前に次の復習が来るよう自動で予定されます（間隔反復）。

**関連するノート：** 右のサイドバーに、まだリンクしていない似た話題のノートが表示されます。**リンク** で結べます。

## デバイス間の同期
Graphite はクラウドフォルダを通じて同期します。保管庫を OneDrive（Windows に標準搭載）、Dropbox、Google Drive、iCloud Drive の中に置き、各パソコンで同じフォルダを開いてください。**設定 → 同期** で、保管庫が同期されているかどうかと、クラウドフォルダの場所を確認できます。

- **2つのデバイスで同時に編集した場合：** 変更箇所がノートの別々の部分なら自動でまとめられます。同じ行が変更されていた場合は、あなたの版がノートに残り、もう一方は「(conflict …)」というコピーとして横に保存されるので、何も失われません。
- **競合コピー**（Graphite またはクラウドアプリが作成したもの）は **設定 → 同期** に一覧表示されます。ある場合はステータスバーに ⚠ が表示されます。
- **スマートフォンでは：** 無料の公式 Obsidian アプリで同じフォルダを開きます。iPhone・iPad では保管庫を iCloud Drive に置きます。Android では FolderSync や Syncthing などのアプリでフォルダをスマートフォンにコピーします。

## プラグイン
Graphite では多くの **Obsidian コミュニティプラグイン** を使えます。

1. **設定**（歯車アイコンまたは `Ctrl+,`）を開き、**コミュニティプラグイン** を選びます。
2. **コミュニティプラグインをオンにする** をクリックします。プラグインは他の人が書いたコードで、ノートを書き換えることもできるため、信頼できるものだけを使ってください。
3. **閲覧** をクリックし、検索して **インストール** を押します。プラグインのフォルダを保管庫内の `.obsidian/plugins/` にコピーしても使えます。
4. スイッチでプラグインをオンにします。オプションがあるプラグインには、横に歯車アイコンが表示されます。

> [!info] 動作するもの
> プラグインのコマンド、リボンアイコン、ステータスバー、設定ページ、Markdown とコードブロックの表示、エディタの入力候補、ファイルメニュー、ポップアップウィンドウ、通知は動作します。独自のサイドパネルを開くプラグインや、エディタそのものを変更するプラグイン（CodeMirror 拡張）は完全には動作しません。読み込みに失敗した場合は、プラグイン名の下に理由が表示されます。

プラグインのフォルダ構成は Obsidian と同じです。Obsidian の保管庫を Graphite で開くと、インストール済みのプラグインが自動的に表示されます。

### プラグインの管理
- **アンインストール：** プラグインの横にあるゴミ箱アイコンで削除します。フォルダは保管庫の `.trash` に移動されるので、元に戻せます。
- **プラグインを再読み込み**（「インストール済みプラグイン」の横にある円形の矢印）で、すべてのプラグインを読み込み直します。プラグインのフォルダをコピーしたり編集したりした後に使います。コマンドパレットからも実行できます。
- **プラグインフォルダを開く**（フォルダアイコン）で `.obsidian/plugins/` をエクスプローラーで開きます。

### サンプルプラグイン：Note Stats
Graphite には小さなサンプルプラグイン **Note Stats** が付属しています。オンにすると次の機能が使えます。
- ステータスバーに読了時間を表示
- 統計ウィンドウ（リボンのグラフアイコン、またはコマンド「Note Stats: Show statistics for this note」）
- 保管庫のノート数・リンク数・タグ数を表示する ```` ```stats ```` コードブロック
- `@today`、`@tomorrow`、`@yesterday` と入力したときの日付候補
- ファイルを右クリックしたときの **Copy wikilink**

コードは `.obsidian/plugins/note-stats/main.js` にあり、自作プラグインの短いお手本になります。

### Dataview
Dataview のクエリ（```` ```dataview ```` ブロック）の結果は **閲覧** ビューと **分割** ビューに表示されます。エディタ内での Dataview のライブプレビューは、Graphite にないエディタ機能を必要とするため動作しません。

## 言語と外観
- 🌐 ボタンまたは **設定 → 一般** で言語を変更できます。最初はシステムの言語で起動します。
- 月のボタンでライト / ダークテーマを切り替えます。
- 本文のフォント、コードのフォント、文字の大きさは **設定 → 外観** で変更できます。編集中だけ等幅フォントで書くこともできます。
- サイドバーの端をドラッグして幅を変え、上部のボタンで表示・非表示を切り替えます。
