# Graphite 使用指南

Graphite 是一款把筆記互相連結起來的筆記應用程式。每篇筆記都是電腦上一般的 Markdown（`.md`）檔案，所以你的筆記永遠不會被鎖在某個軟體裡。

> [!tip] 隨時按 **F1**、點擊左側欄的 **?** 按鈕，或開啟命令面板（按 `Ctrl+P` 後輸入「說明」）即可開啟本指南。

## 交大 Canvas：課件與截止時間

點左下角功能列的**Canvas 按鈕**（大樓圖示）（也可以新增分頁，或在**設定 → 一般**裡）開啟 Canvas，選**使用 jAccount 登入**。所有內容都留在 Graphite 裡：作業、公告、頁面和討論在 Graphite 自己的閱讀器裡開啟，檔案存進筆記庫後直接在 Graphite 開啟。閱讀器顯示不了的（做測驗、回覆討論）用**在 Graphite 的 Canvas 視窗開啟**。

**課件自動到位。**開啟**自動同步新課件**後，Graphite 啟動時和登入期間每 3 小時自動拉取新檔案。在每門課下面選它的**課程資料夾**（Graphite 會先猜，例如 線性代數 → *Linear Algebra*；對不上就新建一個以課程命名的資料夾）。不再有單獨的 Canvas 資料夾：作業筆記放進 `作业 Homework/`，課程要求放在課程資料夾裡，學校原始檔案保存在隱藏位置，不會重複下載。舊的 `Canvas/` 資料夾會在首次啟動時一次性拆開併入各課程資料夾。新檔案按匯入技能的規則歸檔：課件放 `<課程>/課件 Slides/`，作業放 `作業 Homework/`，考試和答案放 `複習資料/`；PowerPoint 和 Word 另存 PDF。課程資料夾裡已有的略過，絕不覆蓋（同名但內容不同的存成「名字 (2)」），刪掉的不會再回來，課程的目錄筆記會加一行連結。Canvas 按鈕上的角標和**新加入課程資料夾**卡片會告訴你加了什麼。想立即同步，點**一鍵拉取所有課程資料**。

**截止時間和一鍵交作業。****未來 30 天**顯示還剩幾天。截止時間旁的**提交作業**會從這門課的作業資料夾裡挑出對應的檔案（按作業編號和標題，再按最新），直接進入預覽；核對後按**確認提交給課程**。確認前絕不會傳送任何內容。也可以在課程的**作業**裡自己從筆記庫或電腦選檔案。在**行事曆訂閱**裡可以加入你的 Canvas 個人行事曆。

## 截圖、歸檔和複習

從 PDF 或學習頁面複製文字，公式和格式常常會亂。改用**截圖**（`Alt+S`、PDF 工具列裡的剪刀，或選取工具列上的**截圖**）：框選公式、圖或表格。截圖面板可以：

- **問 Graphie**：開啟對話，附上截圖。
- **轉成文字**：用**設定 → AI** 裡「截圖轉文字」選的 AI，轉寫成帶 `$…$` 公式的 Markdown，用之前可以修改。
- **加到筆記**：選筆記（剛才開啟的那篇，或「<檔案> 筆記」）和要放進的**小節**，並附上回到這一頁的連結。沒轉文字時直接嵌入圖片（存在 `attachments/`）。
- **不熟悉**：Graphie 立刻在對話裡講解，同時存進 Claude Inbox 記入學習記錄，並產生一張明天複習的卡片。
- **有意思**：以 `[!tip]` 標註放到你選的小節下（也可以交給 Graphie 稍後歸檔）。
- **製卡** / **錯題本**：卡片進入這門課的**卡組**（間隔重複複習），或加入錯題本。

選取文字時，選取工具列上也有同樣的操作。在**複習**頁面，每個卡組都有自己的按鈕，可以只複習這門課。

## 你的儲存庫
- **儲存庫**是存放筆記的資料夾，位置可在 **設定 → 一般** 中查看。
- 想使用其他資料夾（例如已有的 Obsidian 儲存庫），以 `node server.js "D:\儲存庫\路徑"` 啟動即可。
- 刪除的筆記會移到儲存庫的 `.trash` 資料夾，隨時可以找回。
- 在其他程式中修改的檔案會立即顯示在應用程式中。
- 筆記標題可以包含任何字元。Windows 檔名不允許的字元（如 `: ? / " < > * | \ # ^ [ ]`）會替換成外觀相似的字元儲存（例如 `:` 變成 `꞉`）。用一般字元書寫的連結仍然能找到這篇筆記。
- 在桌面版中，有新版本時左側欄和狀態列會出現 **更新** 按鈕。點擊即可安裝，會先儲存你的筆記，然後應用程式自動重新開啟。

## 寫作
- 用右上角的按鈕或 `Ctrl+E` 在 **編輯**、**分欄**（編輯器與預覽左右並排）和 **閱讀** 之間切換。
- 筆記會自動儲存，按 `Ctrl+S` 可立即儲存。
- 修改標題即可重新命名筆記，所有指向它的連結都會自動更新。
- 把圖片貼上或拖入編輯器，會儲存到 `attachments/` 並插入筆記。

| 格式 | 輸入 |
| --- | --- |
| 粗體 / 斜體 | `**粗體**` / `*斜體*`（或 `Ctrl+B` / `Ctrl+I`） |
| 螢光標記 | `==標記==` |
| 刪除線 | `~~文字~~` |
| 標題 | `# 標題`、`## 小標題` |
| 任務 | `- [ ] 待辦`、`- [x] 已完成` |
| 程式碼 | `` `行內程式碼` `` 或用 ```` ``` ```` 包住的程式碼區塊 |
| 隱藏註解 | `%%只在編輯時可見%%` |

全部語法和可複製的範例都在 <a href="#" data-help-page="markdown">Markdown 速查表</a> 中。

## 連結筆記
- `[[筆記名稱]]` 連結到一篇筆記，輸入 `[[` 會出現建議清單。
- `[[筆記名稱|顯示文字]]` 可修改連結文字，`[[筆記名稱#標題]]` 可跳到指定標題。
- `![[筆記名稱]]` 嵌入整篇筆記；`![[圖片.png]]` 顯示圖片，`![[圖片.png|300]]` 設定寬度。
- 指向尚不存在之筆記的連結會顯示為淡色，點擊即可建立該筆記。
- 右側欄顯示 **反向連結**（連結到本筆記的筆記）、**未連結的提及**、**外連**、**標籤** 和 **大綱**。

## 整理
- **資料夾：** 拖曳筆記和資料夾即可移動，按右鍵可進行更多操作。
- **標籤：** 在內文任意位置寫 `#標籤`，或在筆記開頭的屬性裡寫 `tags: [a, b]`。
- **屬性：** 在筆記開頭寫一段用 `---` 包住的 `鍵: 值` 行。
- **日記：** 按 `Alt+D` 在 `Daily Notes/` 中開啟今天的日記。

> [!example] 屬性範例
> ```
> ---
> tags: [專案, 想法]
> status: 進行中
> ---
> ```

## 尋找
- **快速切換**（`Ctrl+O`）：輸入名稱的一部分來開啟筆記；若沒有符合的結果，按 `Shift+Enter` 新增。
- **搜尋**（`Ctrl+Shift+F`）：搜尋所有筆記，條件可以組合使用：

| 搜尋內容 | 找到 |
| --- | --- |
| `會議 記錄` | 同時包含兩個詞的筆記 |
| `"完整詞句"` | 完全一致的詞句 |
| `#專案` | 帶有該標籤的筆記（包括 `#專案/子標籤`） |
| `path:想法` | 某個資料夾中的筆記 |
| `file:草稿` | 名稱包含「草稿」的筆記 |

- **關係圖譜**（`Ctrl+G`）：一張有點像大腦記憶的筆記地圖。拖曳可移動，滾輪可縮放。**局部圖譜** 只顯示目前筆記及與之相連的筆記。
  - **腦區：** 聯繫緊密的筆記會聚成彩色區域，以它們共同的標籤或聯繫最多的筆記命名。
  - **聯想：** 用虛線連接內容相似、但你還沒有連結的筆記。它們是透過比較筆記中的詞語找到的。
  - **記憶：** 記得牢的筆記（根據測驗結果）會發亮，正在遺忘的會變暗，該複習的筆記外面有一圈閃動的橘色圓環。
  - **按一下筆記** 就是「想起它」：一道脈衝沿著它的聯繫擴散開來，卡片按強弱列出它 **讓你想到** 的筆記，並顯示記憶狀態以及 **開啟**、**測驗一下**、**從這裡漫遊** 按鈕。**按兩下** 開啟筆記。
  - **讓思緒漫遊** 會沿著最強的聯繫從一個想法走到下一個，偶爾跳到不相關的想法（⤳），並在底部留下可點擊的 **思路**。

## 標註框
在引用開頭寫 `[!類型]` 即可產生彩色標註框。類型包括 `note`、`tip`、`warning`、`danger`、`success`、`question`、`example`、`quote` 等。在類型後加 `-` 表示預設收合，加 `+` 表示可收合但預設展開。

```
> [!warning]- 點擊展開
> 展開前一直隱藏。
```

## 數學公式（LaTeX）
和 Obsidian 一樣，可以用 LaTeX 撰寫公式：
- **行內公式：** 寫 `$E = mc^2$`，會在句子中顯示為 $E = mc^2$。
- **獨立公式：** 在公式前後各放一行 `$$`，公式會單獨置中顯示：

```
$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
```

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

- **化學式：** 寫 `$\ce{2H2 + O2 -> 2H2O}$`，會顯示為 $\ce{2H2 + O2 -> 2H2O}$。
- **金額不受影響：** `$` 後面緊接空格或數字時不會被當作公式。想在任何地方顯示美元符號，請輸入 `\$`。
- **命令：** 命令面板中的 **插入公式區塊** 會新增一個空的 `$$` 區塊。
- **錯誤：** 有錯誤的公式會以紅色顯示，方便你看出哪裡需要修改。
- **完整列表：** <a href="#" data-help-page="latex">LaTeX 速查表</a>列出約 160 個命令及其效果。也可以在命令面板中選擇 **開啟 LaTeX 速查表**。

## 複習與記憶
Graphite 幫你記住寫下的內容。筆記會自動變成題目：

- 句子中 `==螢光標記==` 或 **粗體** 的詞會變成填空題，`- **術語**：解釋` 會變成「什麼是術語？」。
- 一行寫 `問題 :: 答案`（或依問題、只有 `?` 的一行、答案的順序書寫）會變成記憶卡。
- 每個有標題的段落會變成「關於……你還記得什麼？」。

**檢查錯誤：** 頂端的放大鏡按鈕（`Ctrl+Shift+E`）會檢查目前開啟的筆記。每個問題都顯示為「原文 → 修改後的文字」，並附簡短說明。點擊 **套用** 即可修正（`Ctrl+Z` 可復原），點擊 **在筆記中顯示** 跳到該處，或點擊 **忽略**。不開 AI 時，基本檢查會找出重複的字詞、缺少的空格、失效的 `[[連結]]`（並建議最接近的筆記）、未閉合的 `**`/`==` 以及跳級的標題。開啟 AI 後，AI 還會檢查事實、拼字、文法和表達不清的句子。

**測驗：** 頂端的學士帽按鈕（`Ctrl+Shift+K`）用目前筆記出題測驗你。開啟 AI 後，AI 會為這篇筆記額外出題（筆記內容每變一次只出一次）。離開剛寫過的筆記時，會出現小卡片提議 **檢查** 或 **測驗一下**。兩者也都在右鍵選單中。

**選擇 AI：** 在 **設定 → AI** 中，每項工作（檢查、測驗題、聊天、複習計畫、試卷分析、整理格式）都可以單獨選擇 AI。**Claude Code** 使用這台電腦上的 Claude 視窗，不需要金鑰，但只有在它連線時才能用（在視窗裡說「connect to Graphite」）。**API 模型** 用你自己的金鑰，隨時可用：Anthropic（Claude）、OpenAI、Google Gemini、DeepSeek、通義千問、Kimi、智譜 GLM，或任何相容 OpenAI 的服務。在 **API 金鑰** 中貼上金鑰並按 **測試金鑰**，同時會載入該服務商目前的模型列表。金鑰只儲存在本機，每項工作只傳送對應的筆記或試卷，而且只傳給你選的服務商。檢查和聊天面板裡也可以當場切換 AI。

**複習計畫：** 在複習頁面（或命令面板）按 **產生複習計畫**。填寫考試、日期、考試範圍，勾選範圍內的資料夾，設定每天的時間。AI 會排好到考試前每一天的計畫，先複習薄弱和到期的內容，並帶核取方塊儲存到 `<課程>/复习计划 Review Plans`。

**試卷分析：** 在複習頁面按 **分析試卷**，或在檔案列表裡右鍵一個 PDF 或筆記。AI 會列出每道題的知識點和對應的筆記；如果試卷上有你的答案或分數，還會說明錯在哪裡、為什麼錯，最後給出建議和計畫，儲存到 `<課程>/考试分析 Exam Analysis`。掃描版 PDF 請選 Claude Code。

**整理格式：** 頂端的 🪄 按鈕（`Ctrl+Shift+Y`）會讓目前筆記的格式和同一資料夾裡的其他筆記一致：frontmatter、標題、編號、來源行和 Related 行。內容不變；會先顯示前後對照預覽，套用後可以按 `Ctrl+Z` 復原。

**學習頁面：** 互動式複習頁面在每門課的 `学习页面 Study Pages` 資料夾裡。在檔案列表中點開（或點它的連結）就會在 🎓 分頁中開啟。

**Word 和 PowerPoint：** `.docx` 會以易讀的頁面開啟（按 **精確版面** 可看到和 Word 列印完全一樣的效果）。`.doc`、`.ppt` 和 `.pptx` 會以你電腦上的 Word 或 PowerPoint 產生的 PDF 開啟，可以用頁碼、縮放、搜尋和「連結到某一頁…」；第一次開啟要幾秒，之後會立刻開啟。**儲存 PDF 副本** 會在原檔案旁邊儲存一個 PDF。

**每日複習：** 左側欄的大腦按鈕（`Alt+R`）會顯示今天待複習的題數。每答一題就選 **再一次**、**困難**、**良好** 或 **簡單**，應用程式會在你快要忘記時安排下一次複習（間隔重複）。

**相關筆記：** 右側欄會推薦主題相近、但還沒有連結的筆記。點擊 **連結** 即可把它們連起來。

**錯題本與 PDF 卡片：** 複習頁的錯題本和 PDF 卡片支援按題目或來源搜尋。重做錯題時可以開啟原卷，點 **返回作答** 接著寫。關閉軟體後，也可以繼續尚未提交的草稿。

## 用 AI 學習：執行者與學習設定
Graphite 的學習功能都叫 Graphite 自己的名字：**Graphite 學習助手**（右側聊天）、**Graphite 摘錄**（✦ 標記不熟悉／有趣的內容並整理進筆記）、**Graphite 練習與測驗**，以及檢查、複習計畫、試卷分析、模擬卷、整理格式、**總結 PDF** 和尋找新課程檔案。真正做事的 AI 叫 **執行者**，在 **設定 → AI** 中為每項任務分別選擇：

- **Claude Code**：使用本機的 Claude Code 視窗，不需要金鑰，視窗連線時可用（在視窗裡說「connect to Graphite」）。技能和鉤子在 **設定 → Claude Code** 安裝。
- **本機框架**：**DeepSeek Harness**、**Codex CLI** 等，由 Graphite 在本機啟動，自己讀取檔案（唯讀）。是否已安裝、版本和自訂路徑顯示在 **設定 → AI → 本機框架**。DeepSeek Harness 使用 DeepSeek 的金鑰。
- **API 模型**：Anthropic（Claude）、OpenAI、Google Gemini、DeepSeek、通義千問、Kimi、智譜 GLM，或任何相容 OpenAI 的服務。在 **API 金鑰** 裡貼上金鑰並按 **測試金鑰**。只有對應的筆記或 PDF 文字會傳給你選的服務商。每項工作還有 **此任務的模型**：保持 **預設**（金鑰框裡的模型），或選同一服務商的其他模型，例如測驗用 Haiku、試卷分析用 Opus。

學習助手頂端顯示「執行者：…」，每則回答下也標出是誰回答的；切換執行者後功能名稱不變。

**學習設定：** **設定 → 學習設定** 統一儲存課程資料夾、課程名稱對應（如 `LA = Linear Algebra`）、略過的資料夾、另外查找（最近的下載／桌面／文件）、唯讀資料夾、學習檔案位置、學習資料位置、個人簡介，以及聊天、閱讀和筆記語言。儲存一次，所有執行者都使用同一份設定（儲存在本機 `~/.graphite/study.json`，之後接入的本機 Agent 也能讀取），每項任務只取用它需要的部分。設定不會擴大任何 AI 的讀寫權限。從舊版升級時，原「設定 → AI」與「設定 → Claude Code」中的值會自動合併；兩邊不一致時都會保留，並在學習設定頂端列出供你核對。

## 總結 PDF
在 PDF 工具列點 **總結**，或在檔案樹中右鍵 PDF 選 **總結這份 PDF**（命令面板中也有）。可以只總結部分頁碼：留空表示全部；`0`、超出總頁數或越界的範圍會被直接拒絕，不會傳送任何內容。預設儲存在 PDF 所在的資料夾；如果這份 PDF 是從庫外的課程資料夾匯入的，或放在以課程代號命名的資料夾裡，還會列出對應的課程資料夾供你選擇。唯讀資料夾不能選。

產生的是可編輯的 Markdown 筆記：概述、按章節的要點、關鍵概念、公式，每條後面都有 `p. N` 連結，點擊即開啟原 PDF 的那一頁。預覽中會顯示儲存路徑，點 **儲存** 才會寫入。如果同名總結已存在，可以 **另存為新筆記**，或明確選擇 **更新原筆記**（如果你手動改過，會再提醒一次）。掃描頁沒有文字時，API 模型無法讀取，請選 Claude Code 或本機框架；中途點 **停止** 或儲存失敗都不會改動已有筆記。

## 講義對照與程式碼編輯
**對照筆記：** 開啟講義或筆記，點擊頂端的 **對照筆記**，再選擇要一起看的檔案。寫題解時，點擊 **引用目前頁面** 即可把講義的頁碼連結插入游標處。

**程式碼編輯器：** 在檔案樹中開啟 `.cpp`、`.h`、`.py` 等原始檔，或選擇 **新增程式碼檔案** 開始一道練習。可以直接編輯、`Ctrl+F` 尋找、`Tab`／`Shift+Tab` 調整縮排，按 `Ctrl+S` 儲存（原有編碼和換行符號不變）。**複製目前行連結** 得到的 `[[main.cpp#L42]]` 貼到題解裡，以後點它就跳回這一行。編譯和執行仍在你常用的開發環境裡完成。

## 跨裝置同步
Graphite 透過雲端資料夾同步。把儲存庫放在 OneDrive（Windows 內建）、Dropbox、Google Drive 或 iCloud 雲碟中，然後在每台電腦上開啟同一個資料夾。**設定 → 同步** 會顯示儲存庫是否已同步，以及雲端資料夾的位置。

- **在兩台裝置上同時編輯：** 如果修改的是筆記的不同部分，會自動合併。如果改的是同一行，你的版本保留在筆記中，另一個版本會以「(conflict …)」副本儲存在旁邊，不會遺失任何內容。
- **衝突副本**（無論來自 Graphite 或雲端應用程式）都會列在 **設定 → 同步** 中。有衝突副本時，狀態列會顯示 ⚠ 提示。
- **在手機上：** 用免費的官方 Obsidian 應用程式開啟同一個資料夾。iPhone 和 iPad 上，把儲存庫放在 iCloud 雲碟中。Android 上，用 FolderSync 或 Syncthing 等應用程式把資料夾複製到手機。

## 外掛
Graphite 可以執行許多 **Obsidian 社群外掛**。

1. 開啟 **設定**（齒輪圖示或 `Ctrl+,`），進入 **社群外掛**。
2. 點擊 **開啟社群外掛**。外掛是他人撰寫的程式碼，可以修改你的筆記，請只使用你信任的外掛。
3. 點擊 **瀏覽**，搜尋後點擊 **安裝**。也可以把外掛資料夾複製到儲存庫內的 `.obsidian/plugins/` 中。
4. 用開關啟用外掛。如果外掛有選項，旁邊會出現齒輪圖示。

> [!info] 支援哪些功能
> 外掛的命令、側欄圖示、狀態列、設定頁面、Markdown 與程式碼區塊呈現、編輯器輸入建議、檔案選單、彈出視窗和通知都能正常使用。會開啟獨立側邊面板或修改編輯器本身（CodeMirror 擴充）的外掛無法完整運作。外掛載入失敗時，原因會顯示在外掛名稱下方。

外掛的資料夾結構與 Obsidian 相同。用 Graphite 開啟 Obsidian 儲存庫時，已安裝的外掛會自動出現。

### 管理外掛
- **解除安裝：** 點擊外掛旁的垃圾桶圖示即可刪除。它的資料夾會移到儲存庫的 `.trash`，隨時可以復原。
- **重新載入外掛**（「已安裝外掛」旁的環形箭頭）會重新載入所有外掛，適合在複製或修改外掛資料夾之後使用。命令面板中也有這個命令。
- **開啟外掛資料夾**（資料夾圖示）會在檔案總管中開啟 `.obsidian/plugins/`。

### 範例外掛：Note Stats
Graphite 內建一個小型範例外掛 **Note Stats**。開啟後可以使用：
- 狀態列中的閱讀時間
- 統計視窗（側欄的圖表圖示，或命令「Note Stats: Show statistics for this note」）
- 顯示儲存庫中筆記、連結與標籤數量的 ```` ```stats ```` 程式碼區塊
- 輸入 `@today`、`@tomorrow` 或 `@yesterday` 時的日期建議
- 在檔案上按右鍵時的 **Copy wikilink**

它的程式碼位於 `.obsidian/plugins/note-stats/main.js`，是撰寫自己外掛的簡短範例。

### Dataview
Dataview 查詢（```` ```dataview ```` 區塊）的結果會顯示在 **閱讀** 和 **分欄** 檢視中。Dataview 在編輯器內的即時預覽無法使用，因為它需要 Graphite 沒有的編輯器功能。

## 語言與外觀
- 用 🌐 按鈕或在 **設定 → 一般** 中切換語言。應用程式預設使用系統語言。
- 用月亮按鈕切換淺色和深色主題。
- 在 **設定 → 外觀** 中可以變更內文字型、程式碼字型和字級，也可以在編輯時使用等寬字型。
