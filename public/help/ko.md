# Graphite 가이드

Graphite은 노트를 서로 연결하며 생각을 정리하는 노트 앱입니다. 모든 노트는 컴퓨터에 저장되는 평범한 Markdown(`.md`) 파일이므로 특정 앱에 갇히지 않습니다.

> [!tip] 이 가이드는 **F1**, 왼쪽 리본의 **?** 버튼, 또는 명령어 팔레트(`Ctrl+P`를 누르고 "도움말" 입력)로 언제든 열 수 있습니다.

## 보관함
- **보관함**은 노트가 저장되는 폴더입니다. 위치는 **설정 → 일반**에서 확인할 수 있습니다.
- 기존 Obsidian 보관함처럼 다른 폴더를 쓰려면 `node server.js "D:\보관함\경로"`로 실행하세요.
- 삭제한 노트는 보관함의 `.trash` 폴더로 옮겨지므로 다시 되살릴 수 있습니다.
- 다른 프로그램에서 바꾼 파일은 앱에 바로 반영됩니다.
- 노트 제목에는 어떤 문자든 쓸 수 있습니다. `: ? / " < > * | \ # ^ [ ]`처럼 Windows 파일 이름에 쓸 수 없는 문자는 비슷하게 생긴 문자로 바꿔 저장됩니다(예: `:`는 `꞉`가 됩니다). 보통 문자로 쓴 링크로도 그 노트를 찾을 수 있습니다.
- 데스크톱 앱에서는 새 버전이 있으면 왼쪽 리본과 상태 표시줄에 **업데이트** 버튼이 나타납니다. 클릭하면 설치됩니다. 노트를 먼저 저장하고, 앱은 자동으로 다시 열립니다.

## 작성하기
- 오른쪽 위 버튼이나 `Ctrl+E`로 **편집**, **분할**(편집기와 미리보기를 나란히), **읽기** 보기를 전환합니다.
- 노트는 자동으로 저장됩니다. `Ctrl+S`를 누르면 바로 저장됩니다.
- 제목을 고치면 노트 이름이 바뀌고, 이 노트를 가리키는 링크도 모두 자동으로 바뀝니다.
- 편집기에 이미지를 붙여넣거나 끌어다 놓으면 `attachments/`에 저장되고 노트에 삽입됩니다.

| 서식 | 입력 |
| --- | --- |
| 굵게 / 기울임 | `**굵게**` / `*기울임*` (또는 `Ctrl+B` / `Ctrl+I`) |
| 강조 표시 | `==강조==` |
| 취소선 | `~~텍스트~~` |
| 제목 | `# 제목`, `## 소제목` |
| 할 일 | `- [ ] 할 일`, `- [x] 완료` |
| 코드 | `` `인라인` `` 또는 ```` ``` ````로 감싼 블록 |
| 숨김 주석 | `%%편집할 때만 보임%%` |

모든 문법과 복사할 수 있는 예시는 <a href="#" data-help-page="markdown">Markdown 치트시트</a>에 있습니다.

## 노트 연결하기
- `[[노트 이름]]`으로 노트를 연결합니다. `[[`를 입력하면 제안 목록이 나타납니다.
- `[[노트 이름|보이는 글자]]`로 링크 글자를 바꾸고, `[[노트 이름#제목]]`으로 특정 제목으로 이동합니다.
- `![[노트 이름]]`은 노트 전체를 삽입합니다. `![[이미지.png]]`는 이미지를 보여 주고, `![[이미지.png|300]]`은 너비를 정합니다.
- 아직 없는 노트로 가는 링크는 흐리게 표시됩니다. 클릭하면 노트가 만들어집니다.
- 오른쪽 사이드바에는 **백링크**(이 노트를 가리키는 노트), **연결되지 않은 언급**, **나가는 링크**, **태그**, **개요**가 표시됩니다.

## 정리하기
- **폴더:** 노트와 폴더를 끌어서 옮기고, 마우스 오른쪽 버튼으로 다른 작업을 할 수 있습니다.
- **태그:** 본문 어디에나 `#태그`를 쓰거나, 노트 맨 위 속성에 `tags: [a, b]`를 씁니다.
- **속성:** 노트 맨 앞에 `---`로 감싼 `키: 값` 줄을 씁니다.
- **일일 노트:** `Alt+D`를 누르면 오늘의 노트가 `Daily Notes/`에 열립니다.

> [!example] 속성 예시
> ```
> ---
> tags: [프로젝트, 아이디어]
> status: 진행 중
> ---
> ```

## 찾기
- **빠른 전환기**(`Ctrl+O`): 이름 일부를 입력해 노트를 엽니다. 일치하는 것이 없으면 `Shift+Enter`로 새로 만듭니다.
- **검색**(`Ctrl+Shift+F`): 모든 노트를 검색합니다. 조건을 함께 쓸 수 있습니다.

| 검색어 | 찾는 대상 |
| --- | --- |
| `회의 메모` | 두 단어가 모두 들어간 노트 |
| `"정확한 문장"` | 그 문장과 정확히 일치하는 곳 |
| `#프로젝트` | 그 태그가 있는 노트(`#프로젝트/하위` 포함) |
| `path:아이디어` | 폴더 안의 노트 |
| `file:초안` | 이름에 "초안"이 들어간 노트 |

- **그래프 뷰**(`Ctrl+G`): 뇌의 기억처럼 작동하는 노트 지도입니다. 끌어서 움직이고 휠로 확대·축소합니다. **로컬 그래프**는 현재 노트와 연결된 노트만 보여 줍니다.
  - **영역:** 서로 강하게 연결된 노트가 색깔 있는 영역으로 모이고, 공통 태그나 가장 많이 연결된 노트의 이름이 붙습니다.
  - **연상:** 아직 링크하지 않은, 비슷한 생각을 담은 노트를 점선으로 잇습니다. 노트에 쓰인 단어를 비교해서 찾습니다.
  - **기억:** 잘 기억하는 노트(퀴즈 결과 기준)는 밝게 빛나고, 잊혀 가는 노트는 흐려지며, 복습할 노트에는 주황색 고리가 깜빡입니다.
  - **노트를 클릭**하면 "그 생각을 떠올립니다": 연결을 따라 신호가 퍼지고, 카드에 **떠오르는 것**이 강한 순서로 나옵니다. 기억 상태와 **열기**, **퀴즈 풀기**, **여기서 떠돌기** 버튼도 있습니다. **더블 클릭**하면 노트가 열립니다.
  - **생각 떠돌게 하기**는 가장 강한 연결을 따라 생각에서 생각으로 옮겨 가고, 가끔 관련 없는 생각으로 넘어가며(⤳), 아래에 클릭할 수 있는 **생각의 흐름**을 남깁니다.

## 콜아웃
인용문을 `[!종류]`로 시작하면 색이 있는 상자가 됩니다. 종류에는 `note`, `tip`, `warning`, `danger`, `success`, `question`, `example`, `quote` 등이 있습니다. 종류 뒤에 `-`를 붙이면 접힌 상태로, `+`를 붙이면 펼쳐진 채로 접을 수 있게 됩니다.

```
> [!warning]- 클릭해서 펼치기
> 열기 전까지 숨겨져 있습니다.
```

## 수식 (LaTeX)
Obsidian과 똑같이 LaTeX로 수식을 쓸 수 있습니다.
- **인라인:** `$E = mc^2$`라고 쓰면 문장 안에 $E = mc^2$로 표시됩니다.
- **블록:** 수식 앞뒤 줄에 `$$`를 두면 별도의 줄에 가운데 정렬로 표시됩니다.

```
$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
```

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

- **화학식:** `$\ce{2H2 + O2 -> 2H2O}$`라고 쓰면 $\ce{2H2 + O2 -> 2H2O}$로 표시됩니다.
- **금액 표기는 그대로:** `$` 뒤에 공백이나 숫자가 오면 수식으로 처리하지 않습니다. 달러 기호를 표시하려면 `\$`를 입력하세요.
- **명령어:** 명령어 팔레트의 **수식 블록 삽입**으로 빈 `$$` 블록을 추가합니다.
- **오류:** 오류가 있는 수식은 빨간색으로 표시되어 무엇을 고쳐야 할지 알 수 있습니다.
- **전체 목록:** <a href="#" data-help-page="latex">LaTeX 치트시트</a>에 명령어 약 160개와 결과가 정리되어 있습니다. 명령어 팔레트의 **LaTeX 치트시트 열기**로도 열 수 있습니다.

## 복습과 기억
Graphite은 쓴 내용을 기억하도록 도와줍니다. 노트는 자동으로 문제가 됩니다.

- 문장 속 `==강조==`나 **굵은** 단어는 빈칸 채우기 문제가 되고, `- **용어**: 설명`은 "용어란?"이 됩니다.
- 한 줄의 `질문 :: 답`(또는 질문, `?`만 있는 줄, 답)은 플래시카드가 됩니다.
- 제목이 있는 각 부분은 "…에 대해 기억나는 것은?"이 됩니다.

**오류 검사:** 위쪽의 돋보기 버튼(`Ctrl+Shift+E`)으로 열려 있는 노트를 검사합니다. 문제마다 "원래 텍스트 → 고친 텍스트"와 짧은 이유가 표시됩니다. **적용**으로 고치고(`Ctrl+Z`로 되돌리기), **노트에서 보기**로 해당 위치로 이동하거나, **무시**할 수 있습니다. AI 없이도 기본 검사가 반복된 단어, 빠진 띄어쓰기, 깨진 `[[링크]]`(가장 비슷한 노트 제안), 닫히지 않은 `**`/`==`, 건너뛴 제목 수준을 찾습니다. AI를 켜면 AI가 사실, 맞춤법, 문법, 불분명한 문장도 검사합니다.

**퀴즈:** 위쪽의 학사모 버튼(`Ctrl+Shift+K`)으로 열려 있는 노트의 퀴즈를 풉니다. AI를 켜면 AI가 그 노트에 대한 문제를 추가합니다(노트 내용이 바뀔 때마다 한 번 작성). 방금 쓴 노트를 떠나면 작은 카드가 **검사** 또는 **퀴즈 풀기**를 제안합니다. 둘 다 오른쪽 클릭 메뉴에도 있습니다.

**AI 고르기:** **설정 → AI**에서 작업마다(검사, 퀴즈 문제, 채팅, 복습 계획, 시험지 분석, 서식 정리) AI를 따로 고를 수 있습니다. **Claude Code**는 이 컴퓨터의 Claude 창을 쓰며 키가 필요 없지만, 그 창이 연결되어 있을 때만 작동합니다(창에서 "connect to Graphite"라고 말하세요). **API 모델**은 본인의 키로 언제든 쓸 수 있습니다: Anthropic(Claude), OpenAI, Google Gemini, DeepSeek, Qwen, Kimi, GLM 또는 OpenAI 호환 서비스. **API 키**에 키를 붙여 넣고 **키 테스트**를 누르면 그 제공자의 최신 모델 목록도 불러옵니다. 키는 이 컴퓨터에만 저장되며, 작업에 필요한 노트나 시험지만 해당 제공자에게만 전송됩니다. 검사와 채팅에서는 그 자리에서도 AI를 바꿀 수 있습니다.

**복습 계획:** 복습 페이지(또는 명령 팔레트)에서 **복습 계획 만들기**. 시험, 날짜, 범위를 적고, 범위의 폴더를 체크하고, 하루 시간을 정하세요. AI가 시험일까지 매일의 계획을 약하고 복습할 주제부터 세우고, 체크박스와 함께 `<과목>/复习计划 Review Plans`에 저장합니다.

**시험지 분석:** 복습 페이지의 **시험지 분석**, 또는 파일 목록에서 PDF나 노트를 오른쪽 클릭하세요. AI가 모든 문제를 주제와 해당 노트와 함께 정리하고, 답이나 점수가 있으면 틀린 원인을 설명하며, 조언과 계획을 더해 `<과목>/考试分析 Exam Analysis`에 저장합니다. 스캔한 PDF는 Claude Code를 고르세요.

**서식 정리:** 위쪽 🪄 버튼(`Ctrl+Shift+Y`)은 열린 노트를 같은 폴더의 다른 노트 서식에 맞춥니다: frontmatter, 제목, 번호, 출처와 Related 줄. 내용은 그대로이며, 먼저 전후 미리 보기를 보여 주고, `Ctrl+Z`로 되돌릴 수 있습니다.

**학습 페이지:** 대화형 복습 페이지는 각 과목의 `学习页面 Study Pages` 폴더에 있습니다. 파일 목록에서 클릭하면(또는 링크를 클릭하면) 🎓 탭으로 열립니다.

**매일 복습:** 왼쪽 리본의 뇌 버튼(`Alt+R`)에 오늘 풀 문제 수가 표시됩니다. 답마다 **다시**, **어려움**, **보통**, **쉬움**을 고르면, 잊기 직전에 다음 복습이 오도록 일정이 잡힙니다(간격 반복).

**관련 노트:** 오른쪽 사이드바에 아직 연결되지 않은 비슷한 주제의 노트가 나옵니다. **연결**을 눌러 이으세요.

## 기기 간 동기화
Graphite은 클라우드 폴더를 통해 동기화합니다. 보관함을 OneDrive(Windows에 기본 포함), Dropbox, Google Drive, iCloud Drive 안에 두고, 각 컴퓨터에서 같은 폴더를 여세요. **설정 → 동기화**에서 보관함이 동기화되는지와 클라우드 폴더 위치를 확인할 수 있습니다.

- **두 기기에서 동시에 편집하면:** 바뀐 곳이 노트의 서로 다른 부분이면 자동으로 합쳐집니다. 같은 줄이 바뀌었다면 내 버전은 노트에 남고 다른 버전은 옆에 "(conflict …)" 사본으로 저장되므로 아무것도 잃지 않습니다.
- **충돌 사본**(Graphite이나 클라우드 앱이 만든 것)은 **설정 → 동기화**에 표시됩니다. 사본이 있으면 상태 표시줄에 ⚠ 경고가 나타납니다.
- **휴대폰에서:** 무료 공식 Obsidian 앱으로 같은 폴더를 여세요. iPhone과 iPad에서는 보관함을 iCloud Drive에 두세요. Android에서는 FolderSync나 Syncthing 같은 앱으로 폴더를 휴대폰에 복사하세요.

## 플러그인
Graphite에서는 많은 **Obsidian 커뮤니티 플러그인**을 쓸 수 있습니다.

1. **설정**(톱니바퀴 아이콘 또는 `Ctrl+,`)을 열고 **커뮤니티 플러그인**으로 갑니다.
2. **커뮤니티 플러그인 켜기**를 누릅니다. 플러그인은 다른 사람이 만든 코드이며 노트를 바꿀 수 있으므로 신뢰하는 것만 쓰세요.
3. **둘러보기**를 눌러 검색한 뒤 **설치**를 누릅니다. 플러그인 폴더를 보관함 안의 `.obsidian/plugins/`에 복사해도 됩니다.
4. 스위치로 플러그인을 켭니다. 옵션이 있으면 옆에 톱니바퀴 아이콘이 나타납니다.

> [!info] 작동하는 기능
> 플러그인의 명령어, 리본 아이콘, 상태 표시줄, 설정 페이지, Markdown 및 코드 블록 표시, 편집기 입력 제안, 파일 메뉴, 팝업 창, 알림이 작동합니다. 자체 사이드 패널을 여는 플러그인이나 편집기 자체를 바꾸는 플러그인(CodeMirror 확장)은 완전히 작동하지 않습니다. 플러그인을 불러오지 못하면 이름 아래에 이유가 표시됩니다.

플러그인 폴더 구조는 Obsidian과 같습니다. Obsidian 보관함을 Graphite으로 열면 이미 설치된 플러그인이 자동으로 나타납니다.

### 플러그인 관리
- **제거:** 플러그인 옆의 휴지통 아이콘으로 삭제합니다. 폴더는 보관함의 `.trash`로 옮겨지므로 되살릴 수 있습니다.
- **플러그인 다시 불러오기**("설치된 플러그인" 옆의 원형 화살표)는 모든 플러그인을 다시 불러옵니다. 플러그인 폴더를 복사하거나 수정한 뒤에 사용하세요. 명령어 팔레트에서도 실행할 수 있습니다.
- **플러그인 폴더 열기**(폴더 아이콘)는 `.obsidian/plugins/`를 파일 탐색기에서 엽니다.

### 예제 플러그인: Note Stats
Graphite에는 작은 예제 플러그인 **Note Stats**가 함께 들어 있습니다. 켜면 다음 기능을 쓸 수 있습니다.
- 상태 표시줄에 읽기 시간 표시
- 통계 창(리본의 차트 아이콘, 또는 "Note Stats: Show statistics for this note" 명령어)
- 보관함의 노트·링크·태그 수를 보여 주는 ```` ```stats ```` 코드 블록
- `@today`, `@tomorrow`, `@yesterday`를 입력할 때 날짜 제안
- 파일을 마우스 오른쪽 버튼으로 클릭할 때 **Copy wikilink**

코드는 `.obsidian/plugins/note-stats/main.js`에 있으며, 직접 플러그인을 만들 때 참고할 수 있는 짧은 예제입니다.

### Dataview
Dataview 쿼리(```` ```dataview ```` 블록)의 결과는 **읽기** 보기와 **분할** 보기에 표시됩니다. 편집기 안의 Dataview 실시간 미리보기는 Graphite에 없는 편집기 기능이 필요하므로 작동하지 않습니다.

## 언어와 모양
- 🌐 버튼이나 **설정 → 일반**에서 언어를 바꿉니다. 처음에는 시스템 언어로 시작합니다.
- 달 버튼으로 밝은 테마와 어두운 테마를 전환합니다.
- 본문 글꼴, 코드 글꼴, 글자 크기는 **설정 → 모양**에서 바꿀 수 있습니다. 편집할 때만 고정폭 글꼴로 쓸 수도 있습니다.
- 사이드바 가장자리를 끌어 크기를 바꾸고, 위쪽 버튼으로 숨기거나 보이게 합니다.
