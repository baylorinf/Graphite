# 交大 Canvas

Graphite 用你自己的 jAccount 读取交大 Canvas 上你能看到的课程，把课件放进笔记库，并在应用内提醒截止时间、提交作业。不需要 API 密钥，学校密码只在学校登录页输入。

**1. 登录。**点左下角功能栏的**Canvas 按钮**（大楼图标），或新建标签页选「交大 Canvas」，再点**使用 jAccount 登录**。在弹出的学校页面完成登录（输入密码或扫码），窗口会自动关闭。登录期间页面显示「正在等待」，此时不用再点任何按钮。

**2. 读取课程。**登录后 Graphite 在后台逐门读取课程，同步栏显示进度（如「正在同步… 3/6」）。读取期间可以照常使用 Graphite，已读完的课程会先显示出来。之后应用打开时每 15 分钟自动更新一次课程列表；想马上更新，点**立即同步**。

**3. 课件自动归档。**在每门课下面的**课程文件夹**里选它对应的笔记库文件夹（Graphite 会先按课程名猜一个，比如 线性代数 → *Linear Algebra*；对不上可以选**新建文件夹**）。打开**自动同步新课件**后，Graphite 启动时和之后每 3 小时下载新文件并归档：课件放 `<课程>/课件 Slides/`，作业放 `作业 Homework/`，考试和答案放 `复习资料/`，课程要求放在课程文件夹里；PowerPoint 和 Word 会另存一份 PDF。不想等就点**一键拉取所有课程资料**，只要一门课就点该课的**下载本课文件**。
- 已有的文件跳过，绝不覆盖；同名但内容不同的存成「名字 (2)」。
- 你删掉的文件不会被再次下载。
- 新文件会在 Canvas 按钮上显示角标，并列在**新加入课程文件夹**卡片里；课程的目录笔记会多一行链接。
- 在 Canvas 窗口里手动下载的文件放进笔记库根目录的 `Downloads/`。
- 旧版本的 `Canvas/` 文件夹会在首次启动时自动拆分到各课程文件夹，只做一次。

**4. 看要求、看截止时间、交作业。**作业、公告、页面和讨论在 Graphite 的阅读器里打开；阅读器显示不了的（做测验、回复讨论）点**在 Graphite 的 Canvas 窗口打开**。**课程大纲与要求**是老师发布的课程说明。**未来 30 天**列出即将截止的作业和剩余天数。点截止时间旁的**提交作业**，Graphite 会从这门课的作业文件夹里按作业编号、标题和修改时间挑出最可能的文件并显示预览；核对课程、作业和文件无误后点**确认提交给课程**。点确认之前不会发送任何内容。也可以在课程的**作业**里用**从笔记库选择**或**从电脑选择**自己挑文件。结果不明确时先点**核对提交状态**，确认学校没有收到再重交。

**5. 日历和退出。**在**日历订阅**里粘贴 Canvas「日历 → 日历订阅」的链接，就能在工作台看到所有日程。**退出学校登录**只结束学校网页的登录；**断开账号连接**会清除本机保存的账户、日历订阅和课程缓存，已下载到笔记库的文件保留。

**大概要多久。**
- jAccount 登录：约 1 分钟（取决于输入或扫码的速度）。
- 第一次读取课程：每门课约 30 秒–1 分钟，6 门课一般 3–5 分钟。
- 之后再打开：上次保存的课程立即显示，后台更新一般 1–3 分钟。
- 一键拉取所有课程资料：每个文件约 1–3 秒，几十个文件一般 1–2 分钟；每份 PowerPoint/Word 转 PDF 另需几秒。
- 提交作业：点确认后一般 10–30 秒出现回执。

## 可选的官方 API 接入

有 Canvas Developer Key 的机构可启用应用授权。这个入口支持结构化课程同步、在 Graphite 内提交文本、网址和附件，以及显示校方返回的提交时间与次数。登录和首次写入分别使用只读与提交权限；实际作业提交前显示预览供学生确认。第三方教学工具的作业仍在学校原站完成。

维护者在受管设备的运行环境提供 `GRAPHITE_CANVAS_CLIENT_ID` 与 `GRAPHITE_CANVAS_CLIENT_SECRET`。机构需按 Canvas 原生应用授权配置 `urn:ietf:wg:oauth:2.0:oob`，启用 `canvas-api.js` 的 `SCOPES` 和需要提交时 `canvas-submission.js` 的 `WRITE_SCOPES`。分发给学生的安装包不含机构密钥。开放发布若需启用统一 API 授权，应由机构的受管服务持有密钥。Windows 桌面使用系统加密存储保存连接与课程快照，按笔记库隔离。浏览器开发预览支持学校原站入口和当前服务进程内的日历订阅。
